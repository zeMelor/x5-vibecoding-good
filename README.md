# X5 Tech — «Вайбкодинг добрых дел»

Проект для конкурса **«Вайбкодинг добрых дел»** от X5 Tech, «X5 Клуб» и благотворительного фонда «Выручаем» (23.11.2026 – 07.12.2026).

## О проекте

**Выручаем.AI (Фудшеринг-Диспетчер)** — интеллектуальная система координации фудшеринга для экосистемы **X5 Tech + «X5 Клуб» + благотворительный фонд «Выручаем»**.

- Парсит партии продуктов с подходящим сроком из магазинов и дарксторов + проверяет регламент безопасности фудшеринга.
- Автоматически комплектует сбалансированные продуктовые наборы под профили семей (учитывая аллергии, детей, диабет и срочность `TTL`).
- Оптимизирует маршруты волонтёров на карте (`CVRP + 2-opt`) и начисляет баллы **«X5 Клуба»** + генерирует **«Чек добра»**.

Подробная архитектура, продуктовые модули и математика алгоритмов — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
